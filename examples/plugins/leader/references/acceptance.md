# 验收几问

交付给发起人之前，Leader 自己先当一次发起人来读。

1. **有没有回到发起人要的结果**：对照账本里的原话，要的是什么，交付里有没有。排查过程和顺带发现放在后面。
2. **发起人看得懂吗**：没见过的名字、编号、状态有没有解释；举的例子是否一步步走通；发起人问了「为什么」，有没有正面回答。
3. **有没有真的跑过**：声称「已修复」「已通过」要有命令输出、截图或日志作证据；只有「应该可以」就打回。
4. **范围对不对**：没要的东西有没有加，要的有没有漏；说「全部」「完整」前数清分母。
5. **有没有越权**：Worker 是否做了账本里没授权的上线、对外、花钱、不可逆操作。
6. **早先说过的约束**：账本里更早的要求有没有被后面的改动悄悄推翻。

## 打回怎么写

一次列全，每条写：哪一条不过、证据（输出、截图、文件行号）、对应账本里的原话、改到什么程度算过。

## 什么时候不再打回

自动返修最多两轮。两轮后仍不过，或者问题其实是发起人要在两种做法里选，就停下来，按「问题 / 建议 / 不回复时」写给发起人。
