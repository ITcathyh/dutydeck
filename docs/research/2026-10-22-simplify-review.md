# Dutydeck simplify 审查与优化

审查基线：`71909066acf1d00a515d55ffce27617921fa57e5`。工作分支：`refactor/simplify-20261022`。

本轮由 Codex 执行本机 Claude Code 2.1.308 内置 `/simplify` 的流程，未调用 Claude Code 执行审查。原指令包含复用、简化、效率、机制层次四个独立角度；四项均由 Astra 审查。受三个子 agent 并发槽位限制，前三项并行，第四项随后运行。用户指定全项目，因此范围扩展到全部已跟踪源码。修复由 Sol worker 在独立 worktree 完成，最终 diff 另交未参与编写的 Astra 复审。

## 范围与方法

基线共 1,595 个已跟踪文件。复用和简化扫描读取全部 1,413 个 `.ts/.tsx/.js/.mjs/.mts` 文件，共 346,072 行；机制层次扫描还覆盖 HTML、CSS、JSON、SQL、patch 和 YAML，共 1,513 个文本文件、370,648 行。91 个 JSON 文件均可解析。审查覆盖 `apps/server`、`apps/web`、全部 `packages/*`、插件、内置插件、示例、脚本和测试，并沿候选项的调用方、数据流和保护条件核实。

这是全目录扫描加候选项的语义核查，不是逐行人工审计全部源码。未验证真实外部 CLI、飞书线上调用、Windows/macOS 运行行为或线上整体性能。静态资产、历史录屏和转写只做范围盘点及必要上下文检查。

## 未采纳项

- 保留 ACP/PTY 路径差异、旧配置 URL 识别、工具终态单调性及 ACPX 持久化保护；未证明能在保持行为的前提下合并。
- 保留安全文件读取的前后身份检查、Herdr 的控制器代次检查。Herdr 已有状态去重，并不存在最初怀疑的每次轮询重复写盘。
- 保留历史迁移和 V1/V2 schema 的独立定义，不让旧版本依赖当前版本。
- 不合并独立 CLI、平台插件、安装期脚本及测试对照算法的小型重复；这些实现有协议、依赖定位或独立验证边界。
- 不批量并发化队列、输入、插件 hooks 或同步 SQLite 查询；这些操作有顺序和容量约束。
- 不增加未经测量的全局缓存、LRU 或通用调度框架。前端已有增量投影和窗口缓存。
- 保留已有 smoke/harness 的基线差异及历史验收脚本策略；不借清理更改验收语义。
