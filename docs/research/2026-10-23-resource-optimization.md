## 明确撤回的候选

| 候选 | 复审证据与决定 |

| 按文件元数据缓存会话扫描结果 | 同长度覆盖可保留相同文件指纹；Astra 的 500 次真实解析器对照中有 286 次缓存结果错误。完整撤回，不加时间窗口规避反例。 |
| 插件历史回执的两个 partial index | 大库查询显著变快，但合法状态写入和小工作集生命周期有额外成本。撤回索引及配额 SQL 调整。 |
| work-item 子关系反向索引 | 1 item 样本的生命周期 P95 2.5991→3.1454 ms，CAS/rename/delete 总耗时七轮均更慢。撤回索引、v44 和相关版本变更。 |
| 构建期 gzip | 首版 34 个压缩副本中 4 个与最终 JS/CSS 不一致，已修复并逐字节验证；后续受控实验仍确认 gzip/旧产物路径成本。尽管受限网络首屏 6.51→2.60 秒，仍不纳入交付。最终没有 gzip 插件、编码协商、sidecar 或新增运行时缓存。 |
| 大日志 concat/rope | 18 个真实浏览器样本功能检查全部通过；32 MiB 隐藏阶段 CPU 和采样堆大降，但 1 MiB 已开追加及 8 MiB 关闭/重开三轮均更慢。实验源码已恢复，不以隐藏阶段收益换交互回退。 |

大日志实验覆盖 1/8/32 MiB 各三对交错样本，真实 HTTP/SSE、完整长度与 Unicode 首尾、滚动两端、输入、首次打开、已开追加、关闭重开及会话切换均验证。32 MiB 隐藏 100 帧的主线程耗时 5290.78→848.38 ms，采样 JS 堆峰值 1026.19→69.84 MiB；但 1 MiB 已开追加主线程中位数增加 4.44%，8 MiB 关闭耗时 98.47→190.50 ms，重开增加 4.44%。这些是被拒实验数据，不计交付收益。大 DOM 检查不是全文 digest；精确字符串与旧快照等价另由小型单测验证。采样 JS 堆不是浏览器 RSS 或真实总峰值。
